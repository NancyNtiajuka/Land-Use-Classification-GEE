# Land-Use-Classification-GEE
Supervised land use/land cover classification using multispectral satellite imagery, training datasets, and machine learning in Google Earth Engine.
# Land Use Classification Using Google Earth Engine
#Study Area: Abia State

## Project Overview
This project focuses on land use and land cover classification using Google Earth Engine and supervised machine learning techniques.

The analysis was conducted using multispectral satellite imagery and training datasets to classify different land cover types.

## Objectives
- Develop a land use classification workflow
- Apply supervised classification methods
- Analyze spatial distribution of land cover
- Generate classified thematic maps

## Tools & Technologies
- Google Earth Engine
- GIS & Remote Sensing
- Satellite Imagery(sentinel-2)
- Spatial Analysis
- Machine Learning Classification

## Workflow Methodology
The project workflow involved preliminary preprocessing and scripting experiments in Google Colab, including raster preparation and geospatial data handling. Shapefile extraction and preprocessing were conducted in QGIS before integrating the datasets into Google Earth Engine for land use classification.

Due to challenges encountered during raster merging and project time constraints, the final classification workflow and analysis were completed using Google Earth Engine and QGIS.


## Outputs
- Classified land use maps
- Spatial analysis results
- Training sample datasets
- Environmental interpretation
